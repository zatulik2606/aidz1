### Итерация 1 — Инфраструктура, конфиг, базовый бот
- [x] Инициализировать проект через `uv` (`pyproject.toml`)
- [x] Добавить зависимости: `aiogram`, `openai`, `python-dotenv`
- [x] Создать структуру папок (`src/`, `tests/`)
- [x] Создать `.env.example` с перечнем всех обязательных переменных
- [x] Создать `Makefile` с командами `install`, `run`, `docker-build`, `run-docker`, `docker-down`
- [x] Реализовать `src/config.py`: загрузка и валидация переменных из `.env`, fail fast при отсутствии обязательных
- [x] Настроить логгирование через stdlib `logging` в `stdout`
- [x] Реализовать `src/main.py` и `src/handlers.py`: запуск polling, обработчик `/start`

**Проверка:** Бот запускается через `make run` и отвечает на `/start` в Telegram.
