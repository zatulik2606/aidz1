# Идея LLM-ассистента в виде Telegram-бота

## Описание

Интеллектуальный ассистент на базе LLM, реализованный как Telegram-бот. Выступает в роли **инженера мониторинга** на сети эксплуатации ИТ-продуктов: помогает дежурному персоналу проводить первичный анализ поступающих аварийных событий, предлагать версии причин и шаги по локализации.

## Основные задачи ассистента

- Ведение диалога с пользователем в чате Telegram
- Первичный анализ аварийных событий: классификация, вероятные причины, рекомендации по локализации
- Ответы в рамках заданной роли инженера мониторинга (через системный промпт LLM)
- Сохранение контекста общения в рамках одной сессии для последовательного разбора инцидента

## Ключевые особенности

- Использование LLM для анализа инцидентов и генерации рекомендаций
- Роль и поведение ассистента задаются через системный промпт (`SYSTEM_PROMPT` в конфигурации)
- Доступ через Telegram — без необходимости устанавливать дополнительные инструменты
- Облачный деплой на Railway — бот доступен 24/7 без локального сервера

## Сценарии применения

- Первичная диагностика аварийных событий на сети эксплуатации ИТ-продуктов
- Помощь дежурному инженеру в быстром определении вероятных причин инцидента
- Подготовка первичного отчёта о проблеме для передачи в профильную команду
