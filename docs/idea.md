# Идея ИИ-продукта: ИИ-агент-консультант

## Описание

Планируется развить базового ИИ-ассистента в полноценный ИИ-продукт в роли **ИИ-агента-консультанта**. Продукт работает через Telegram-чат, помогает пользователю выбрать подходящее направление консультации, отвечает на вопросы по материалам компании и доводит диалог до оформления заявки.

## Основные задачи ассистента

- Ведение консультационного диалога в Telegram-чате
- Ответы на вопросы пользователя на основе документов компании: портфолио, услуги, описания программ и курсов
- Проверка актуальных фактов в интернете, если информация может быть устаревшей или модель не уверена в ответе
- Мягкое ведение пользователя к оформлению консультации через уточняющие вопросы
- Сбор и фиксация заявки: имя, контакт и суть запроса

## Техническая основа

- Локальная разработка и запуск CLI выполняются только внутри виртуального окружения `.venv`.
- Зависимости управляются через `uv`; стандартные команды: `make install`, `make run`, `make test`.

## Ключевые особенности

- Единый консультант по продуктам и услугам компании в Telegram
- Опора на внутренние материалы компании для содержательных и предметных ответов
- Дополнительная проверка внешних фактов для повышения актуальности ответов
- Проактивный сценарий конверсии из диалога в заявку на консультацию
- Фокус на понятных, коротких и полезных ответах без перегруза

## Сценарии применения

- Пользователь задает вопрос о компании, услугах или программах и получает ответ по материалам из базы документов
- Пользователь спрашивает про условия или детали, бот уточняет и при необходимости сверяет данные с актуальной информацией из интернета
- В ходе диалога бот предлагает консультацию и подводит к оставлению контакта
- Пользователь оставляет имя и способ связи, бот фиксирует заявку и подтверждает, что обращение принято
